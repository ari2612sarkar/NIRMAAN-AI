# NIRMAAN AI — Frontend

Next.js (App Router) + TypeScript + Tailwind dashboard for the NIRMAAN AI
waste intelligence platform. See the repository root `README.md` for the
full project overview and setup instructions.

```bash
npm install
npm run dev
```

Expects the backend running at `NEXT_PUBLIC_API_BASE_URL`
(`.env.local`, defaults to `http://127.0.0.1:8000`).
